# Microsoft Visual C++ runtime

The files `msvcp140*.dll`, `vcruntime140*.dll` and `concrt140.dll` next to
`can_analyzer.exe` (if present) are the Microsoft Visual C++ Redistributable
runtime libraries. They are distributed unmodified for application-local
deployment, as permitted by the Microsoft Visual Studio license terms for
redistributable code. They remain the property of Microsoft Corporation.

If you prefer a system-wide runtime, install the official "Microsoft Visual
C++ Redistributable (x64)" and delete these files.
